A one-line resignation letter from a cron job that has had enough, written by a small deterministic Python program (`main.py`) for the [make.fun bounty](https://make.fun/bounty/u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947).

Running `main.py` writes the letter to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
